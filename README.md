# Customer Behaviour Data Analysis

## **Overview**
This project focuses on analyzing customer purchasing behavior using Python, SQL, and Power BI. The workflow includes data cleaning, exploratory data analysis (EDA), SQL-based business analysis, dashboard creation, and reporting to generate meaningful business insights and support data-driven decision-making.

---

## **Dataset**
The dataset contains customer transaction and purchasing information, including:
- Customer demographics
- Product details
- Purchase history
- Discounts applied
- Ratings and reviews
- Sales and revenue data

---

## **Tools & Technologies**
- Python
- PostgreSQL / MySQL / SQL Server
- Power BI
- Pandas
- NumPy
- Matplotlib
- SQL

---

## **Project Workflow**

### **1. Data Loading**
- Imported dataset using Python
- Connected database with SQL environment

### **2. Data Cleaning**
- Removed null and duplicate values
- Corrected inconsistent data
- Standardized column formats

### **3. Exploratory Data Analysis (EDA)**
- Customer purchasing trends
- Revenue analysis
- Product performance analysis
- Discount impact analysis

### **4. SQL Analysis**
- Revenue and sales queries
- Customer segmentation
- Product-wise analysis
- Review and rating analysis

### **5. Dashboard Development**
Created an interactive Power BI dashboard featuring:
- KPI metrics

- Customer insights

### **6. Reporting & Presentation**
- Generated business insights report
- Created presentation slides summarizing findings
